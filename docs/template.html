Routing account review

Each week of a model-routing rollout, this tool pulls the router's routing-decision export, prices every turn against the model the engineer would have used without routing, and checks each opt-in engineer's failures, tool-call errors, failovers and latency. It ends with one call for the engineering lead: widen routing to the whole team, or hold.

Data

The engineers, traffic and failure rates are made up for one example org of 40 engineers. Every row uses the field names of the open-source Weave Router's export schema, and every price comes from the router's own price book and cost code (weave-os/router, Apache-2.0). The weekly note is drafted by Claude and appears here only once a live run has been recorded.

Run it yourself

Python 3.11 or later. From the repo folder:

pip install -e ".[dev]"
python -m account_review.cli synth --week week1 --out exports/week1.ndjson
python -m account_review.cli review exports/week1.ndjson
pytest -q

With a read-only analytics key, pull reads a live export instead.
